核心能力

不是拼接，是深度融合。每个模块都经过端到端测试验证。

声纹识别

CAM++ 192 维声纹向量。识别"谁在说话"。HK MIC 四通道采集。注册/验证/待定池机制。

🗣️

全双工语音

唤醒 + ASR + 对话 + TTS 全链路。SenseVoiceSmall 转写，edge-tts 自然语音播报。

📷

真实视觉

USB 摄像头 + Kimi k2 多模态 AI。所有图像描述来自真实硬件，绝不编造。

🧠

自进化 Skill

每次硬件操作自动生成 SKILL.md。重复任务 2-3x 加速，Token 降低 60%。

📋

Memos 笔记

8 种智能分类 + 用户画像聚合。离线 SQLite。客户需求追踪驱动产品迭代。

🔧

硬件控制

GPIO/I2C/UART/PWM 全栈 HAL。MCU 紧急停止。control_car / control_arm 已预留。

产品形态

硬件 + App + 桌宠，三端合一

同一个橘派服务器，手机 App、桌面宠物、Web 面板同时连接。

🤖

轮足机器人

橘派搭载于机器人平台。UART 连接 RT1064 MCU 控制双电机。支持前进/后退/转向/停止。

App → WS:8765 → 橘派 → UART → RT1064 → 电机

Android App

最低 Android 6.0 · 横屏触控 · 电机/对话/提醒/健康/紧急
